✨ Social Spark

A little spark can brighten someone's day.

📱 About the App
Social Spark is an Android application designed to encourage positive social interaction and help people share kindness and positive messages with others.

The purpose of the app is to create a simple and friendly space where users can interact with positive content and spread encouragement.

The application was developed using Android Studio and Kotlin.

🎯 Purpose of the App
The main purpose of Social Spark is to encourage users to spread positivity and kindness.

The app was designed to:

Encourage positive interactions.
Provide users with a simple and easy-to-use interface.
Allow users to interact with the application's features.
Create a friendly and welcoming user experience.
Demonstrate my understanding of Android development using Kotlin.
🎨 Design Considerations
I designed Social Spark with simplicity and ease of use in mind.

Colours
I used colours that create a positive and welcoming feeling. The colours help make the application visually appealing while keeping the text easy to read.

Layout
The layout was kept simple so that users can easily understand where to find the different features of the application.

Buttons
The buttons were designed to be clear and easy to identify. This helps users understand what action they need to take.

Fonts and Text
I used clear and readable text so that users can easily understand the information displayed on the screen.

User Experience
The overall design focuses on making the application simple, friendly and easy to navigate.

💻 Development
The application was developed in Android Studio using Kotlin.

Kotlin was used to create the application's functionality, while Android Studio was used to design, develop and test the application.

⚠️ Error Handling
The application includes input validation and error handling to help prevent invalid information from being entered.

When the user enters incorrect information, the application provides feedback to help the user understand what needs to be corrected.

The error messages are designed to be clear and helpful rather than confusing the user.

🧪 Testing
I manually tested the application to make sure that the different features work correctly.

Testing included:

Checking that the application launches correctly.
Testing user input.
Checking buttons and user interactions.
Checking that error messages appear when incorrect information is entered.
Checking that the application does not crash during normal use.
Testing the application on an Android device/emulator.
No unit tests were required for this project.

📊 Logging
Logging was used during development to help understand what was happening while the application was running.

Logs can help identify errors and make it easier to troubleshoot problems in the application.
